# features/

Componentes y lógica por módulo de negocio (grupos, niños, aportes, regalos). Opcional: si un componente o hook es específico de un flujo y se usa en una sola ruta, puede vivir aquí; si es reutilizable, en `components/` o `lib/`.

Estructura sugerida: `features/groups/`, `features/children/`, etc., cada uno con sus componentes de formulario o listas si se desea separar de `app/`.
